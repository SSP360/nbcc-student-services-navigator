# Service-Resolution Traces

**Status**: Concept demonstrator. Every number and quote below is real output from the
current deterministic pipeline (`lib/retrieval.ts`, `lib/routing.ts`, `lib/escalation.ts`),
generated by directly invoking those functions and reproduced here verbatim — nothing is
fabricated or hand-written to look plausible. Traces 4 and 5 were updated in P0
(`feat/p0-five-journey-ux`) after curating `NBCC-SS-004` and `NBCC-SS-006`; Traces 1–3 are
unchanged from Days 5–7. Queries are synthetic/demonstration questions, not real student
input; none was collected from, or entered by, an actual student. This is a demonstration
of routing and escalation mechanics, not counselling, crisis intervention, or a live
service.

Reproduce any trace yourself: run `npm run dev`, then `GET /api/dev/routing?q=<query>`
with any query below (development mode only, per `NODE_ENV` gating) for the full internal
detail shown in these tables, or visit `/` and use the learner UI (backed by the
production-safe `GET /api/navigate?q=<query>`, available in every environment) to see the
plain-language version a learner would actually see.
